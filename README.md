# Audio and Image Signal Processing

This repository contains two MATLAB projects that explore signal-processing techniques for audio signals and digital images.

## Audio Processing

The audio-processing project focuses on analyzing and modifying a noisy speech recording. It includes:

- Audio noise reduction
- Frequency-spectrum analysis using the Fourier transform
- Low-pass and frequency-band filtering
- Audio speed modification
- Signal reversal
- Frequency-domain audio mixing
- Waveform and spectrogram visualization

## Image Processing

The image-processing project explores spatial-domain and frequency-domain techniques. It includes:

- Manual implementation of 2D convolution
- Horizontal and vertical edge detection
- Edge enhancement
- Gaussian filtering
- Feature-map construction
- Max pooling
- Two-dimensional Fourier analysis
- Low-pass, high-pass, band-pass, and Laplacian filtering

## Overview

Together, these projects demonstrate how concepts such as Fourier analysis, filtering, feature extraction, and signal transformation can be applied to different forms of digital data.
